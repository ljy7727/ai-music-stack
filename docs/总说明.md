## 一、15 个项目一览

按用途分成五组。⭐ 是 GitHub Star 数，「评分」是 10 分制自评（效果 50% + 成熟度 30% + 易用性 20%）。

### 🎤 第一组：人声分离（把人声和伴奏拆开）

| 文件夹 | 是什么 | 干什么用 | ⭐ | 评分 | 怎么启动 |
|---|---|---|---|---|---|
| `UVR5` | **Ultimate Vocal Remover v5.6 官方图形界面（Roformer BETA 版）** | 人声/伴奏分离、多轨、去混响/去噪/去回声、Matchering 母带匹配、对轨对齐、批量 | 26,571 | 9.0 | 双击 `UVR5\启动.bat` |
| `VocalSeparator` | audio-separator 脚本/网页版（用同一批 UVR 模型） | 同上，但可命令行批量、可编程；含卡拉OK专用模型 | 1,413 | 8.5 | 双击 `VocalSeparator\启动.bat` → http://127.0.0.1:7899 |

> **两者关系**：UVR5 是"软件"，VocalSeparator 是"同一批模型 + 脚本外壳"。
> **UVR5 适合手动挑模型、看波形、试听；VocalSeparator 适合批量丢文件、写脚本自动化。**
>
> ⚠️ **关键点**：官方 v5.6 标准包**不支持 Roformer**（当前质量天花板），所以装的是 **Roformer BETA 版**。
> 两个目录的模型是**硬链接共享**（同一份数据、两个名字），合计 8.8 GB，不占双份。
> **模型已全部预置，UVR5 界面里不用再点下载**（本机网络环境下 UVR 自带下载会失败）。

### 🗣️ 第二组：人声 / 歌声（换音色、唱新歌）

| 文件夹 | 是什么 | 干什么用 | ⭐ | 评分 | 怎么启动 |
|---|---|---|---|---|---|
| `RVC` | RVC 2.3 整合包 | **变声 / 翻唱**：原曲人声一键换音色；可训练自己的音色；实时变声 | 38,693 | 9.0 | 双击 `RVC\启动.bat` → http://127.0.0.1:7898 |
| `DiffSinger` | OpenUtau 编辑器 + 声库 + 声码器 | **逐音符填歌词唱歌**：中文自动转拼音、逐字控音高/颤音 | 3,220 | 8.5 | 双击 `DiffSinger\OpenUtau\OpenUtau.exe` |
| `SoulX-Singer` | 零样本歌声合成（Apache-2.0） | **30 秒参考音色就能唱新歌**（F0/MIDI 双控，中/英/粤）+ 免转写翻唱 | 997 | 8.0 | 双击 `SoulX-Singer\启动(歌声合成).bat` |
| `YingMusic-Singer` | 零样本歌声合成 + 编辑 | 给音色参考 + 歌词 + 旋律就能唱；旋律可直接给音频自动提谱 | 77 | 7.0 | 双击 `YingMusic-Singer\启动.bat` |

**三条唱歌路线怎么选：**
- **想逐字精修音高** → DiffSinger（OpenUtau）
- **只想把现成整首歌换成别的音色**（不改词） → RVC
- **想用任意音色唱任意歌、懒得扒谱** → SoulX-Singer（推荐）或 YingMusic-Singer

## 二、重要备注

### 网络（本机特有，重装/换机时先看这条）

| 目标 | 本机情况 | 对策 |
|---|---|---|
| `github.com` 直连 | ❌ 不通 | 走代理 `127.0.0.1:7897`，或 `gh-proxy.com` 镜像 |
| `raw.githubusercontent.com` | ❌ 不通 | 走代理（`requests` 走代理会 502，**curl 走代理正常**） |
| `huggingface.co` | ❌ 不通 | 全部换成 **`hf-mirror.com`** |
| `modelscope.cn` | ✅ 通 | 大权重优先走这里（ACE-Step、HeartMuLa、Stable Audio 3） |
| `dl.fbaipublicfiles.com` | ✅ 通 | Demucs 权重 |

### 代理冲突（踩过的坑）

本机系统代理 `127.0.0.1:7897` 会拦截 **Gradio 的 localhost 自检**（报 502，网页打不开）。
所有启动脚本已内置：

```
set "NO_PROXY=localhost,127.0.0.1,::1"
```

若哪个界面打不开，**先查这一条**。

另外还有一个更隐蔽的坑：环境变量里存在一个**失效的代理端口**（`HTTPS_PROXY=http://127.0.0.1:50022`），
它能打开 github 仓库首页、却拉不动 release 资产 —— 导致"看起来网络是通的，但模型全下不来"。
本机**真正可用的是 `127.0.0.1:7897`**，判定通道是否可用必须拿**真实发布包**做探针，不能拿仓库首页。

### UVR5 / VocalSeparator 的模型下载

两边的模型**已全部预置好（8.8 GB，硬链接共享）**，正常使用**不需要再下载**。

- UVR5 界面里的 "Download Center" **在本机大概率失败**（它用 `requests` 走代理，会 502）
- 要补模型请用 `VocalSeparator\下载模型.bat`（走 curl + 真实发布包探针，已实测可用）
