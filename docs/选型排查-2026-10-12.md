## 四、缺口清单（这是本次排查最重要的部分）

1. **没有"整首歌生成"**——你的 7 个项目里，没有任何一个能"给歌词 + 风格 → 出一首带人声和伴奏的完整歌"。DiffSinger 只管人声轨、ACE/RVC 只管换音色。这是最大的功能空白，**ACE-Step 1.5 正好填（MIT、13.4k★、本机可跑）**。
2. **没有"视频→音效/自动配音"的实用选择**——只有 Woosh（权重禁商用、质量中游）。想给视频配 foley，`MMAudio`（轻量）或 `HunyuanVideo-Foley`（质量强、许可受限）才对口。
3. **零样本唱歌这一条选错项目**——YingMusic-Singer 只有 77★、无 LICENSE、仅旋律驱动无逐音符时长控制，做出来的歌声和伴奏对不齐；Alpha 级替代就是 **SoulX-Singer**（997★、Apache-2.0、MIDI+F0 双控、中英粤、还顺带给了免转写翻唱）。
4. **音效组全是英文提示词**——总说明里那条"中文描述先让 AI 翻译成英文"的限制，**MOSS-SoundEffect v2 直接解决**（中英双语 + 48kHz + Apache-2.0 干净商用）。
5. **SA3 只装了最小档**——medium/large 是"零成本、同代码"的画质升级。
6. **无实时/交互音乐**——`Magenta RealTime 2` 可补，但属可选项。

## 六、针对本机（RTX 4070 Ti SUPER 16GB）的行动建议

**P0｜补最大缺口**
1. **装 ACE-Step 1.5**——`ace-step/ACE-Step-1.5`，MIT。官方给了 Windows 便携 7z 包 + `uv sync` 两条路（Python 3.11–3.12）。16GB 显存按官方表选 **2B sft**（稳）或 **XL-turbo + CPU offload**（画质更高）。权重有 ModelScope 镜像，走你现有习惯的镜像链路即可。
2. **用 SoulX-Singer 替换 YingMusic-Singer**——Apache-2.0、自带 `webui.py`（歌词+MIDI）和 `webui_svc.py`（免转写翻唱）。环境是 conda python 3.10（本机没有 conda 的话用 `venv` 等价替代），权重 `hf download Soul-AILab/SoulX-Singer` 走 hf-mirror。它一个模型同时覆盖"填词开唱"和"翻唱换音色"两个老需求。

**P1｜低成本高收益**
3. **补 Stable Audio 3 的 medium / large 权重**（显存约 6.5GB / 9GB，16GB 无压力），两个都是同仓库同代码，装完就是音效组最强档。
4. **装 MOSS-SoundEffect v2**——中文提示词 + 48kHz + Apache-2.0，音效组从此不用再"先翻译成英文"。
5. **视频配音按需取舍**：先上 `MMAudio`（~6GB 显存，够用）；只有确实要做电影级 foley 再考虑 HunyuanVideo-Foley（许可与显存都要额外接受）。

**P2｜可选**
6. `Applio`（想自己训音色/融合模型再装；RVC 日常换音色不必）。
7. `HeartMuLa/heartlib` 或 `Magenta RealTime 2`（想玩实时演奏/多语言整曲）。
8. `audio.cpp`（以后想做不带 Python 环境的离线小工具时再考虑）。
9. 建议把 **TangoFlux** 降级为"最快出草稿"的试验品、**Stable Audio Open 1.0** 留作对照，两者都不必再投入精力。

**明确不建议**：YuE（本机 16GB 不够、要多半天的渲染）、so-vits-svc / seed-vc（上游停更）、DiffRhythm 2（已被 SA3 超过）。
